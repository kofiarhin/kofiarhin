## Engineering Approach

- Separate deterministic application logic from probabilistic AI behaviour
- Prefer typed schemas and validated structured outputs at system boundaries
- Use agents, RAG, vector databases, and orchestration only when they materially improve the product
- Keep consequential AI actions observable and human-controlled where appropriate
- Prefer TDD and evidence-backed verification over unverified completion claims
- Build the smallest complete vertical slice before adding complexity
