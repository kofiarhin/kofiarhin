## Engineering rules

- Separate deterministic application logic from probabilistic model behaviour
- Prefer typed schemas and validated structured outputs at boundaries
- Keep consequential actions observable and human-controlled
- Prefer evidence-backed verification over unverified “done” claims
- Ship the smallest complete vertical slice before adding complexity
